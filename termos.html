2. Objecto Do Serviço

O VMP SaaS é um sistema de ponto de venda (POS) e gestão, que inclui:

  • Software desktop (Flutter) para operação
  • Painel de administração web para gestão
  • Sistema de licenciamento e subscrição
  • Relatórios de vendas e stock
  • Suporte técnico conforme o plano contratado

4.1 Concessão

Após pagamento confirmado, concedemos uma licença não exclusiva, não transferível e revogável para usar o VMP SaaS no número de máquinas contratado.

4.2 Restrições

4.3 Activação E Machine ID

Cada licença está vinculada a um Machine ID único. Se mudar de computador, contacte o suporte para transferência de licença (sujeito a aprovação).

5.1 Por Incumprimento

Podemos suspender ou rescindir a licença imediatamente se:
